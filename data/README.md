# Data policy

This public repository does not contain ROS bags, point clouds, images, model
weights, field coordinates, or hardware logs.

Future datasets should be represented by a manifest containing their source,
license or permission, access class, size, SHA-256 checksum, ROS topics,
message types, frames, recording time, and intended experiment. Small public
fixtures may use Git LFS; large or restricted data should remain in approved
object storage, NAS, or a DVC remote.
